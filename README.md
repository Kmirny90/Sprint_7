#Sprint_7 Тестирование API учебного сервиса "Яндекс Самокат"

## Описание проекта
Автоматизированное тестирование API сервиса "Яндекс Самокат". Проверяются основные ручки:
- Создание курьера
- Логин курьера
- Создание заказа
- Получение списка заказов

# Технологии
- Python 3.14
- pytest
- requests
- allure-pytest
- Faker

## Список тестов

### Создание курьера (POST /api/v1/courier)
- Успешное создание курьера
- Создание двух одинаковых курьеров (ошибка 409)
- Создание без обязательных полей (login, password)
- Создание без поля firstName (успех)
- Создание с уже существующим логином (ошибка 409)

### Логин курьера (POST /api/v1/courier/login)
- Успешный логин
- Логин без логина
- Логин без пароля
- Логин с неправильным логином
- Логин с неправильным паролем
- Логин несуществующего курьера

### Создание заказа (POST /api/v1/orders)
- Создание заказа с разными цветами (параметризация):
  - BLACK
  - GREY
  - BLACK + GREY
  - без цвета
- Проверка наличия track в ответе

### Получение списка заказов (GET /api/v1/orders)
- Получение списка заказов
- Проверка структуры ответа
- Пагинация (limit, page)

## Данные для тестов
- Статические данные хранятся в папке `data/`
- Случайные данные генерируются через Faker в `generators.py`
- Для каждого теста создаются уникальные данные
